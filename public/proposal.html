1. Project Overview

You are building a B2B mobile top-up / recharge distribution platform — the middleman between retailers (who sell recharges to end customers) and DingConnect (the global wholesale API provider).

Your Role: Platform Owner / Middleman
What you provide: A branded portal + API where retailers can:
1. Create an account & get approved by you
2. Load money into their wallet on your platform
3. Use your platform's recharge features to send mobile top-ups via DingConnect
4. Track transaction history, download receipts
What DingConnect provides: The actual mobile top-up delivery to operators worldwide

Similar Platforms (Reference)

  • core-retail.com — C-Top platform (your reference)
  • Ding.com — DingConnect's own consumer-facing platform
  • Recharge.com — International top-up aggregator

2. How You Make Money (Commission Model)

You earn as the middleman by adding a markup on the DingConnect wholesale price. When a retailer recharges £10 on your platform, you charge them £10.50. DingConnect charges you £10. You pocket the £0.50 difference.

Example Commission Flow

Step Party Amount Description
1 Retailer (customer of yours) £11.00 Pays you for the top-up (your retail price)
2 You (Platform Owner) £0.60 Your commission/margin (≈5.5% markup)
3 DingConnect £10.40 Their wholesale price for the actual top-up
4 End Customer £10.40 value Receives the mobile credit on their phone

Commission Structure Options

📊 Flat Markup Model (Recommended)

Add a fixed % markup on top of DingConnect's wholesale price. Simple and transparent.

  • Default: 2.5% — 5% markup
  • Per retailer override: Give better rates to high-volume retailers
  • Per operator: Higher markup on expensive operators, lower on popular ones

💡 Volume-Based Tiers

Reward high-volume retailers with lower commission rates:

Monthly VolumeYour Commission
< £1,0005%
£1,000 — £5,0003.5%
£5,000 — £20,0002.5%
> £20,0001.5%
⚠️ Key Insight: The DingConnect API shows you the retail price (what end-customers pay). You set your own selling price per retailer/operator in your admin panel. The difference between what you charge the retailer and what DingConnect charges you = your gross profit per transaction.

Additional Revenue Streams

  • Wallet top-up fees: Add a small fee (e.g., 1.5%) on payment gateway deposits
  • Failed transaction fees: Charge a small fee for unsuccessful recharges
  • Monthly subscription: Charge retailers a small monthly fee for platform access
  • API access fees: If you allow retailers to use your API programmatically, charge a higher rate

6.3 Real-Time Notifications (Pusher)

When a transaction is created or updated, the system broadcasts events via Pusher. The retailer's browser listens in real-time:

  • TransactionCreated — New recharge submitted, shows "Processing..."
  • TransactionUpdated — Status changed (success/failed), shows result immediately
  • WalletUpdated — Balance changed (credit/debit), updates wallet display
  • NotificationReceived — System alerts (KYC approved, wallet credited by admin)

Commission Calculation in Code

// When a transaction succeeds, your commission is:
$commissionAmount = ($transaction->amount * $commissionRate) / 100;

// Example:
$transaction->amount = 10.00;  // What DingConnect charges
$commissionRate = 5.5;          // Your markup percentage
$commissionAmount = (10.00 * 5.5) / 100 = 0.55;
// Retailer was charged: 10.55
// You keep: £0.55 per transaction

11. How DingConnect Works (For Your Understanding)

DingConnect is a wholesale mobile top-up provider. They have contracts with 500+ mobile operators in 150+ countries. You buy from them at wholesale rates and sell to retailers at retail rates.

The Two Pricing Flows

Flow A: Fixed Top-Up (Amount-based)
Retailer wants to send exactly £10 to a phone.
You know the cost from DingConnect (£9.80).
You charge the retailer £10.00.
Your margin: £0.20 per transaction.
Flow B: Free Range (SKU-based)
Retailer selects a specific operator plan (e.g., "Airtel ₹249 plan").
DingConnect tells you the retail price (£2.80).
You set your own selling price (e.g., £3.00).
Your margin: £0.20 per transaction.

What DingConnect Provides

  • API Credentials: API Key + Customer ID (you get these after signing up)
  • Wholesale rates: Per-operator, per-country pricing
  • Webhook callbacks: Real-time transaction status updates
  • Operator catalogue: 500+ operators across 150+ countries
  • Settlement: They bill you monthly for all transactions
